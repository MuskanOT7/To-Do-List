# 📝 To-Do List Web App (InternPE Internship Project)

This project is a **To-Do List Web Application** developed as part of my **InternPE Internship**. It helps users manage daily tasks efficiently with a clean and responsive interface.

---

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed (checkbox)
* ❌ Delete tasks
* 💾 Data stored using **Local Storage** (tasks remain after refresh)
* 🎨 Modern UI with gradient background and clean design
* 📱 Responsive layout

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation & Local Storage)

---

## 📂 Project Structure

```
To-Do-List/
│── index.html
│── style.css
│── script.js
```

---

## ⚙️ How It Works

* Users can type a task in the input box and click **Add**
* Each task includes:

  * Checkbox (to mark complete)
  * Delete button (✖)
* Completed tasks are styled with a **line-through effect**
* All tasks are saved in **browser localStorage**, so they persist even after refreshing

---

## ▶️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Start adding your tasks 🎯
